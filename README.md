## Hey! It's *nifanfa*, a loyal .NET hobbyist programmer.

Introducing **BootTo.NET**: imagine a pure bare-metal UEFI environment powered by a minimalist C# runtime. Unlike my other C# operating system projects, *BootTo.NET* delivers near-full C# feature support directly via UEFI—including `FileStream`, Sockets, asynchronous `Task`s, and more. 

You can build and run whatever you want in **pure C#**, completely independent of Linux, Windows, or macOS.

https://github.com/nifanfa/BootTo.NET

**Tip:** *BootTo.NET* features a conservative GC implementation, setting it apart from toy projects like Cosmos or MOSA.
